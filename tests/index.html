ANY-INK test pages

Minimal pages that load one feature at a time. Run with npm run pages. Never in the production build.

  • index — this page: proves a page here can import from src/
  • history — settings entries, creation undo, aliasing fix
  • metrics — draggable metrics and guides layer
  • kerning — pair view drag, exception groups, tile-picker dialogs, lookup
  • preview-strip — preview strip against simpleExampleProject
  • sliders — slider rows (transforms panel + global actions) standalone
  • storage — kv / recovery IndexedDB stores, remembered file handles, permission re-request
  • files — open / save / save as / download, export folder, recents card (Chrome or Edge)
  • recovery — crash-recovery snapshots, Web Lock per project, restore card (close the tab to simulate a crash)
  • assets — image asset store: add / refuse types, .gs2 base64 round trip, blob-map round trip
  • trace — trace layer: drop or paste an image, opacity, move / resize on the canvas, Trace panel
  • autotrace — auto-trace: potrace worker smoke test, binarize, preview on the canvas, Auto-trace card
  • autosave — real browser file writes, external conflicts and crash recovery
  • fontcheck — font check: break small a three ways, see the strip line, the true-width preview and the export toast
  • undo — undo that never surprises (B2): one press undoes the newest change wherever it is; opening letters is never a step (All tools)
  • spacing — automatic spacing (B3): the gap rule at 1,000 and 2,048 units, side kinds (measured when not in the table), the letter-spacing slider, edge drags, photos following the ink
  • placement — placement on the guide lines (B3): one scale per photo, one writing line per row, tails kept; real auto-trace of the fixture photos
