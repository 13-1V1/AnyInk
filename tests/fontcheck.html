Font check

Loads the Oblegg sample, then breaks one thing at a time: small a, the space, or a kern pair. The font check runs 2 seconds after the last change and lists everything the font file can't hold, by name. Export keeps the "where it went" words and adds the names, with an amber edge and a Show me button (here Show me only logs where it would go). Each break starts from a fresh copy of the sample. The preview line uses each letter's true width, so a letter with no width piles up, and a space with no width runs words together.
