Trace layer

Drop a PNG, JPEG, or WebP photo or scan on the canvas (or paste one) to trace over it. The Trace panel sets its opacity; with the Trace panel open and the arrow (Resize) tool, drag an empty part of the image to move it and drag a corner to resize it. A press on a shape selects the shape. Every other tool draws over it. The image is saved in the project file but never exported.

Decoding and drawing

Pick a photo to run it through the decoder the import uses: PNG, JPEG, or WebP only, phone photos turned upright, the long side capped at 2000 pixels, stored as WebP. It lands on the current character as its trace image. Try a sideways phone photo, an image over 2000 pixels, a GIF, and an iPhone HEIC photo (each gets a plain message). The buttons below change the drawing directly: opacity, invert (for the slate canvas), and a trace whose image is missing, which draws only its box.

Canvas layer

Choose the Trace panel above, then add the test image (3 by 2, so a stretched resize would show). Hover the image for the move cursor and a corner for a diagonal resize cursor. Drag the body to move it (Shift moves in steps of 10). Drag a corner to resize it with the opposite corner fixed (Shift resizes from the center). Press Escape during a drag to put it back. Arrow keys nudge 1 (Shift 10) while no shape is selected; one Undo takes back a whole burst of presses. Locked, hidden, another panel, or any tool but the arrow: the mouse goes to the tool. Metric lines win where they cross the image, except on its corner handles. A press on a shape (or a selected shape's handle) over the image goes to the shape; empty paper inside the image grabs the image.

Panel and import

Drop a PNG, JPEG, or WebP file from Explorer on the canvas, paste one with Ctrl+V, or use the buttons. The first image opens the Trace panel: the opacity slider redraws live and makes one Undo step on release; Show, Lock, Invert colors, Fit to em, Fit to cap height, Replace, and Remove are one Undo step each. Draw glyph as outline is a view setting (no Undo step). The HEIC and GIF buttons should each show a plain message and add nothing. The big photo (about 5 MB of noise) should show a loading message first.

Keyboard check: click Lock, Show, Invert colors, Draw glyph as outline, the opacity slider, or Fit to em with the mouse, then click the canvas and press Ctrl+Z. The last change is undone and the "keys go to" card reads "the canvas". Space then pans (it no longer flips the checkbox), and arrow keys move the image, not the slider. Tab to a checkbox and press Space: it keeps the focus, as keyboard use should. Then click the image on the canvas and press Ctrl+Z: that change is undone too, because any press on the canvas takes the keyboard back.

Paste check: copy an image in Chrome, come back, and press Ctrl+V without clicking the canvas first: it is traced with no clipboard prompt. Copy a shape (Ctrl+C or the Copy button), switch windows and back, and Ctrl+V pastes the shape at once. Block the clipboard in the site settings and repeat the image paste: it still works, because the paste itself carries the image.

Drop check: drag a photo over the Trace panel (its cards get a dashed green outline) and drop it there: it is traced as on the canvas. Drop one anywhere else on this page: the page stays put (no image opens, no "Leave site?" prompt) and it is traced too.
