ANY-INK preview strip

The <preview-strip> below is mounted against a ProjectEditor loaded from src/samples/simpleExampleProject.json (glyphs: space, A, B, C and the ligature AB) with no app around it. Type in the strip, drag the size slider (Shift snaps to 10 pt), open Presets, flip Real font / Metrics, and double-click a glyph in the strip to select it.

Drive the editor

B1: honest preview (turn Real font on first, type "AAA BCA")

A with a fractional width used to make Real font quietly fall back to a system font; it now builds at the rounded width. A with width 0 piles up in Real font exactly as in the font file. A gap of 12.5 between A and C is a real font that can't be built: the sheet must say "Can't show your font yet: the gap between Capital A and Capital C needs fixing." and show no text, and Show me must go to that gap on the Kerning page (logged here).

B1: font check line (the real check, src/anyink/fontcheck)

The line names the first letter, says how many more letters and gaps need fixing, and offers Fix it for a width, a space with no width or the letter's own stray shapes (one Undo step each; the line moves on at once); otherwise it says what to do. While it shows, the corner of the sheet under it is cut out of the letters, so at 200 pt no letter runs under the line, and the letters never move when it comes or goes.
